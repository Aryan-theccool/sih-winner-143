## What we have built so far

### 1. Backend (FastAPI)

- **`backend/main.py`** — REST API over precomputed `casefiles/KERALA_2025_CASE01/`
- Endpoints: `/api/case`, `/api/detection`, `/api/drift/*`, `/api/vessels`, `/api/ranking`, `/api/scene.png`, evidence export
- Serves built frontend from `frontend/dist/`
- **No ML inference at request time** — reads GeoJSON, JSON, CSV, PNG from disk

### 2. Processing pipeline (offline batch)

Runnable via `python -m pipeline.run_all`:

| Step | Module | Output |
|------|--------|--------|
| Synthetic met-ocean | `casegen/make_met.py` | Wind/current NetCDF |
| Synthetic AIS | `casegen/make_ais.py` | 20 vessels, 48 h tracks, gaps |
| Synthetic SAR scene | `casegen/make_sar.py` | GeoTIFF + `scene_preview.png` |
| F1 Detection | `ml/unet_inference.py` + `ml/classical_detect.py` | Slick polygons, detectability mask |
| F2 Drift | `drift/opendrift_run.py` | Hourly backtrack/forecast GeoJSON, manifest |
| F4 Ranking | `ranking/rank.py` | LightGBM scores + TreeSHAP reasons |
| F5 Evidence | `evidence/make_pdf.py` | PDF dossier + SHA-256 hashes |

### 3. Frontend (React + deck.gl + MapLibre)

- **ORIGINTRACE SAGAR-NETRA** command-centre UI
- Unified map shell: SAR overlay, oil slick layers, origin cloud, vessel replay
- Panels: Detection, Origin, Vessels, Evidence, Report
- AIS timeline replay (TripsLayer + ship icons)
- Dark-vessel gap trails and pulsing markers
- SHAP-style attribution readout for top suspects
- UNCLOS tip-and-cue banner, evidentiary ladder, regulatory mapping
- Layer toggles, origin hindcast auto-play, dossier export modal
- Landing/marketing pages under `frontend/src/landing/` (separate from main app)

### 4. Demo assets

- **`casefiles/KERALA_2025_CASE01/`** — full synthetic case (inputs + outputs)
- **`evidence_KERALA_2025_CASE01.pdf`** — sample sealed report
- **`ship.png`** — custom vessel map icon
- **`video.mp4`** (repo root) — **present but not wired into the detection engine or UI pipeline**

## What works today (demo mode)

When you run:

```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

and open **http://localhost:8000**:

1. UI loads precomputed detection, drift, vessels, ranking
2. Map shows Esri **World Imagery** basemap (online) + **synthetic SAR preview** overlay (`/api/scene.png`)
3. Oil slick polygons, origin cloud, and vessel tracks animate from cached data
4. Panels show probabilities, age estimates, SHAP reasons, UNCLOS framing
5. Evidence export can generate/ reference the PDF bundle

This matches the PRD **“staged demo — pre-computed data, live UI”** model.

## What we are NOT doing (important)

### ❌ Not using real satellite imagery for detection

- The SAR layer is a **physics-driven synthetic scene** generated by `casegen/make_sar.py`, labeled in metadata as *“synthetic fallback scene — Zenodo-mode”*.
- It is **not** a downloaded Copernicus Sentinel-1 GRD granule processed in real time.
- The map basemap is **third-party satellite tiles** (Esri) for geography only — **not** the input to our detection model.

### ❌ Not running detection on satellite video

- **`video.mp4`** (and `frontend/public/landing/hero-video.mp4`) are **marketing / visual assets only**.
- There is **no** pipeline step that:
  - ingests MP4 or frame sequences,
  - segments oil from video,
  - or feeds video frames into U-Net / classical detector at runtime.
- The engine does **not** “watch” a spill video and identify it live.

### ❌ Not doing live inference in the browser session

- The UI **never** calls PyTorch, OpenDrift, or LightGBM during a judge demo.
- All `/api/*` responses are **static files** produced earlier by `pipeline.run_all`.
- Re-running the engine requires a **manual pipeline run** on the server, not a button in the UI.

### ❌ Not connected to operational feeds

- **AIS:** synthetic CSV (`synthetic_48h.csv`), not NAIS/IMAC/live aisstream.io
- **Wind/current:** synthetic ERA5/CMEMS-like fields, not live pulls during demo
- **U-Net weights:** training script exists; **no shipped production checkpoint** in repo (inference uses classical/physics path for the demo case)

### ❌ Not claiming detention-grade evidence

- Outputs are framed as **tip-and-cue / Art. 220(3) request-for-information**
- Chemical fingerprinting, ORB reconciliation, and Art. 220(6) enforcement grade are **explicitly out of scope**

## Architecture (as deployed)

```
┌─────────────────────────────────────────────────────────────┐
│  Browser UI (React + deck.gl)                               │
│  — reads /api/* only, no compute                            │
└───────────────────────────┬─────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│  FastAPI (backend/main.py)                                  │
│  — serves JSON/GeoJSON/PNG from casefiles/                  │
└───────────────────────────┬─────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│  casefiles/KERALA_2025_CASE01/  (PRE-COMPUTED)              │
│  inputs: synthetic SAR, AIS, met                            │
│  outputs: detection, drift, ranking, evidence               │
└───────────────────────────┬─────────────────────────────────┘
                            │ produced by (offline)
┌───────────────────────────▼─────────────────────────────────┐
│  pipeline.run_all  — NOT called during live demo            │
│  casegen → ml → drift → ranking → evidence                  │
└─────────────────────────────────────────────────────────────┘
```

**Not in this loop:** `video.mp4`, live satellite downlink, runtime model serving.
